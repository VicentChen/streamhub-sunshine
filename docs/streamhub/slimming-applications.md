# 本机应用执行与启动钩子裁剪

2026-09-13，在 StreamHub 项目的 Sunshine 子模块实施。此批删除本机应用执行，保留 Moonlight 应用列表与会话控制所需的元数据和状态。

## 已删除

- 本机应用命令、独立后台命令、准备/撤销命令及全局启动钩子。
- 工作目录、输出日志、提权执行、自动分离、子进程组等待和退出超时。
- 命令环境变量生成、配置中的环境变量展开及平台命令执行辅助代码。
- 托盘删除后失去调用者的浏览器启动辅助函数。
- 上述功能的 Web 表单、状态标签、配置解析、英文说明与专属样式。
- 本机应用默认示例、外部命令测试、Boost.Process 与 Boost.Program_options 构建依赖，以及命令专属的 Windows Userenv 链接。

## 保留行为

- 应用名称、封面、原有基于名称和图片的 ID 算法。
- Moonlight 应用列表、启动请求中的应用选择、恢复与结束接口。
- 应用选择只记录会话使用的应用 ID，不表示执行了本机程序，也不代表已接入 StreamHub Provider。
- 普通名称和图片的 ID 算法不变；原先含环境变量表达式的名称或图片路径不再展开，按字面值读取。
- Web 应用管理 API 读取时只返回名称与封面，保存的条目也只包含这两项元数据。旧文件中的执行字段不再执行；读取不会自动重写用户文件。
- 新安装的默认应用列表为空，已有用户应用文件不由此次代码修改覆盖。

本批结束时尚未裁剪的显示器管理、音视频本机后端和虚拟输入，现已在 [媒体与设备后端裁剪](slimming-core.md) 中删除。Web 管理整体、UPnP 和跨平台支持范围没有在本批新增决定。未添加新的分辨率、帧率、会话数或输入能力限制。

## 验证

- Web 生产构建已通过。
- Linux ARM64 主程序及 C++ 测试目标构建通过。
- 13 个套件、70 项回归全部通过。结果位于 `cmake-build-slimming-baseline/slimming-applications.xml`，复现入口为同目录的 `validation-applications.py`。测试隔离 HOME、配置、临时目录及覆盖率输出。
- 主机信息接口正常响应；SIGTERM、SIGINT 均以退出码 0 正常结束，约 0.02 秒退出。
- Git 空白检查通过；生产二进制不再包含本机应用执行和全局钩子函数。
- 相对上一批结束时的快照，本批净减少约 2,470 行文本内容（含配套配置、页面及测试）。
- 新增回归覆盖：旧命令字段不会执行、未知应用不改变选择、选择与结束状态、元数据文件无需环境配置、原有 ID 与重复名称处理、无效文件报错，以及经过认证与 CSRF 校验的应用管理 API 元数据读写。
