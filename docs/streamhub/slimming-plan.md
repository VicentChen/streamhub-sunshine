# Sunshine 瘦身计划

状态：已完成本计划中明确决定的删除项，构建与回归结果见 [完整裁剪记录](slimming-core.md)。Web 管理整体、UPnP、跨平台支持仍待单独决定。目标是减少代码、配置、构建和部署负担，降低长期维护成本。

## 1. 范围

Sunshine 在本项目中承担 Moonlight 协议端职责。已有模块边界见 [开发规范](../../AGENTS.md) 和 [项目架构](../../../docs/architecture.md)。

本计划只做功能裁剪与必要的依赖解耦：

- 保留必要功能，不要求保留它们当前所在的整个文件、框架或全部配置项。
- 删除功能时同时清理其调用、配置、页面、依赖、专属测试和打包内容。
- 不借瘦身增加新功能、替代系统或产品约束。
- Receiver 接入属于独立开发工作，不在本计划中安排，也不以完成 Receiver 开发作为整份瘦身计划的前置条件。
- Provider 当前的分辨率、帧率、会话数量、音频及手柄实现状态，不作为本次裁剪后新增的 Sunshine 限制。
- 不将清理构建缓存和 Git 历史算作功能瘦身成果。

## 2. 必须保留的功能

| 功能 | 保留内容 | 不因此保留的内容 |
| --- | --- | --- |
| Moonlight 发现与主机信息 | 主机发现、稳定标识、状态查询 | 托盘与桌面集成 |
| 配对、认证与凭据持久化 | 可信连接、证书与已配对客户端状态 | 无关的管理功能 |
| 应用列表与会话控制接口 | Moonlight 使用的列表、启动、恢复和结束接口 | 本机应用执行、命令和启动钩子 |
| RTSP 协商与会话管理 | 媒体参数协商、连接生命周期、断线与资源释放 | 显示器调整和本机编码器探测 |
| 视频网络传输 | 编码视频的分包、时间戳、RTP、FEC、加密和发送 | 本机采集、视频编码和图像处理 |
| 音频编码与传输 | PCM 到 Opus、必要的声道处理和网络发送 | 本机音频采集和设备管理 |
| 客户端控制消息 | 关键帧请求、保活及串流控制的协议处理入口 | 硬件控制和编码器策略实现 |
| 手柄协议消息 | Moonlight 手柄消息解析及反馈封装 | 本机虚拟手柄、驱动和主机专属实现 |
| 基础设施 | 上述功能实际使用的网络、计时、线程、配置、日志及状态存储 | 已无调用的通用框架和配置分支 |
| 测试与授权材料 | 保留功能的相关测试、GPL 许可证和必要第三方声明 | 仅覆盖已删除功能的测试与失去对应内容的说明 |

应用列表与启动接口、控制消息处理入口保留，不在此次任务中另行实现 Provider 输入列表映射或控制协议适配。

## 3. 删除对象

### 3.1 本机媒体和设备后端

- 全部本机屏幕采集后端，包括 X11、Wayland、KMS、Portal、KWin 以及其他平台的桌面采集实现。
- 全部本机视频编码后端，包括软件编码、NVENC、VAAPI、Vulkan Video 及其他平台编码实现。
- 仅供本机视频编码使用的像素转换、缩放、GPU 资源和编码器探测逻辑。
- 显示器枚举、模式切换、配置恢复等本机显示管理。
- 本机录音、音频设备枚举、切换和恢复。
- 本机虚拟 HID、虚拟手柄和键鼠注入。
- 本机应用启动、命令执行、准备/撤销命令及相关进程管理。
- 托盘及与上述功能绑定的桌面集成。

按实际使用关系删除，共用代码拆出必要部分后再处理；不整包删除仍被保留功能使用的平台工具。

### 3.2 随功能清理的内容

- 启动时初始化、退出清理、能力探测及后台工作线程。
- 配置字段、默认值、解析、校验、API 和 Web 设置入口。
- 构建源码项、依赖探测、库链接、代码或资源生成。
- 不再使用的 shader、图标、辅助程序、第三方子模块及安装规则。
- 仅属于已删除功能的测试、文档、CI 和打包任务。

不通过永久保留大量关闭的开关来完成裁剪；确认无使用者的实现应从源码和依赖图中移除。

## 6. 完成判断

本次完成判断围绕减法本身：

1. 已决定删除的功能及其专属维护内容得到清理。
2. 必须保留的协议、传输和基础能力没有被误删。
3. 生产构建依赖能够解释，保留项有实际使用者。
4. 文档如实反映当前功能与缺口，没有把后续接入工作写成已实现。
5. 没有新增分辨率、帧率、会话数、音频或手柄等产品限制，也没有扩展新功能。

Receiver 接入、Provider 能力扩展、完整硬件串流验收不计入本次完成条件。无法在当前实现中运行的端到端场景单独列明，不宣称通过。
